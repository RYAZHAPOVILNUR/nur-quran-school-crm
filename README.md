# CRM школы Корана «Нур»

Простая CRM для школы Корана: ученики и семьи, группы и расписание, посещаемость с телефона, хифз (сданные страницы, мураджаа, законченные джузы), оплаты и должники, заявки, зарплата учителей.

- Сначала для телефона: нижняя панель, крупные кнопки, посещаемость отмечается в одно касание.
- Полностью на русском, даты в формате ДД.ММ.ГГГГ, деньги в рублях.
- Данные хранятся в SQLite-файле `data/nur.db`. Каждый день делается копия в `data/backups/`, хранятся 14 последних.
- Ничего не удаляется насовсем: у учеников меняется статус, оплаты отменяются с указанием причины, все действия пишутся в журнал.

## Запуск

Нужен Node.js 22.13 или новее (проверено на Node 24). Внешних зависимостей нет: `npm install` не нужен.

```bash
npm start
```

Откройте http://localhost:3000. При первом запуске база сама заполнится демо-данными.
Чтобы открыть с телефона в той же Wi-Fi-сети, зайдите на `http://<IP-компьютера>:3000`.

| Команда | Что делает |
|---|---|
| `npm start` | запуск (порт можно задать через `PORT=4310 npm start`) |
| `npm run dev` | запуск с автоперезапуском при правках |
| `npm test` | 12 автотестов: 9 сценариев приёмки и проверки прав |
| `npm run reset` | сохранить текущую базу в `data/backups` и начать с чистых демо-данных |

## Демо-входы

На экране входа есть кнопки быстрого входа. Логины и пароли для обычного входа:

| Роль | Логин | Пароль |
|---|---|---|
| Владелец — Абдуллах | `abdullah` | `nur-owner` |
| Администратор — Марьям | `maryam` | `nur-admin` |
| Учитель — Юсуф | `yusuf` | `nur-teacher` |
| Учительница — Аиша | `aisha` | `nur-teacher` |
| Учителя Ибрагим и Абдурахман | `ibragim`, `abdurahman` | `nur-teacher` |

Для рабочего режима демо-кнопки отключаются переменной `DEMO_MODE=0`, а пароли нужно сменить.

## Кто что видит

Права проверяются на сервере в каждом запросе, а не только скрытием кнопок.

| | Владелец | Администратор | Учитель |
|---|---|---|---|
| Ученики, семьи, заявки | всё | всё | только ученики своих групп |
| Посещаемость | все группы | все группы | свои группы |
| Хифз | смотрит и вносит | смотрит | вносит у своих учеников |
| Оплаты и долги | да | да, вносит оплаты | нет |
| Зарплаты, прибыль, цены | да | нет | нет |

Роль `parent` уже есть в схеме (`users.family_id`), так что кабинет родителя добавляется как ещё одна роль с доступом только к своей семье.

## Как устроено

```
server/
  index.js        HTTP-сервер, маршрутизация, раздача статики, заголовки безопасности
  db.js           схема SQLite (встроенный node:sqlite), транзакции, журнал действий
  auth.js         пароли (scrypt), сессии в httpOnly-cookie, матрица прав
  billing.js      начисления, скидка второму ребёнку, долги, зарплата
  hifz.js         прогресс по 604 страницам и 30 джузам, фиксация законченных джузов
  alerts.js       «три пропуска подряд без уважительной причины»
  students.js     запись в группу: проверка пола и мест, лист ожидания
  seed.js         демо-данные
  api/*.js        обработчики по разделам
shared/           справочники и мусхаф (общие для сервера и браузера)
public/           интерфейс: чистый JS, ES-модули, без сборки
test/             автотесты сценариев приёмки
```

### Правила расчёта

- Абонемент начисляется за месяц каждому, кто учится в групповом классе. Если ученик пришёл после 20-го числа, начисление начинается со следующего месяца.
- Индивидуальное занятие начисляется за каждый проведённый урок (отметки «был» и «опоздал»).
- Скидка 10 % даётся второму и следующим платящим детям семьи по дате начала учёбы. Ученики на садаке в этот счёт не входят.
- Садака: начисление сохраняется с пометкой «бесплатно», в долг не идёт, сумма видна в финансах.
- Долг — это неоплаченные прошлые месяцы плюс текущий, если уже прошло 10-е число. До 10-го текущий месяц показывается как «ожидаем».
- Каникулы для всей школы или пауза группы: за отмеченный месяц абонемент не начисляется, а уже начисленный отменяется.
- Зарплата: число проведённых уроков × ставка учителя. Урок засчитывается тому, кто отметил посещаемость, в том числе при замене.
